KEYBOARD PREDICTOR: BOILERPLATE (starter) FILES

What is in this folder
- predictor_starter.py : your starter code. Fill in every TODO.
- predictor_app.py     : the web page for step 8. It uses your finished starter.
- requirements.txt     : the packages you need for the web page (gradio and a recent jinja2).
- books/alice.txt      : Alice's Adventures in Wonderland (Lewis Carroll, 1865). Public domain, from Project Gutenberg.
- books/sherlock.txt   : The Adventures of Sherlock Holmes (Arthur Conan Doyle, 1892). Public domain, from Project Gutenberg.

Setup
1. You need Python 3.10 or newer.  Check:  python --version   (Windows: py --version)
2. Steps 1 to 7 need nothing to install.
3. For step 8 (the web page) install the packages once:
     pip install -r requirements.txt

Run
- The starter:   python predictor_starter.py     (Windows: py predictor_starter.py)
- The web page:  python predictor_app.py         then open http://127.0.0.1:7860
Keep the files and the books folder together, and run the commands from that folder.
Do not add share=True to the web page: it makes a public link to your computer.
